# DecodeLabs Internship - Project 2

## 📊 Project Title
Interactive Sales Dashboard using Microsoft Excel

## 📖 Description
This project was completed as part of the DecodeLabs Data Analytics Internship. The objective was to analyze sales data and build an interactive dashboard using Microsoft Excel. The dashboard helps users understand sales performance through KPIs, Pivot Tables, Pivot Charts, and Slicers.

## 🎯 Features
- Interactive Dashboard
- KPI Cards
- Pivot Tables
- Pivot Charts
- Slicers
- Sales Analysis
- Dynamic Filtering

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers

## 📂 Files Included
- Project2.xlsx

## 🚀 How to Run
1. Download the Excel file.
2. Open it in Microsoft Excel.
3. Enable Editing (if prompted).
4. Use the slicers to interact with the dashboard.
